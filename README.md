# florianleux.fr

[Voir le site / See the site](https://florianleux.fr)

## 🇫🇷 En français

Mon site personnel, qui réunit mes deux métiers : développeur frontend et illustrateur.

- **Art** : illustrations, personnages, dessins traditionnels, études et animations (avec les timelapses de réalisation)
- **Dev** : mes jeux (Ahoy!, La Haute Tour) et mes conférences techniques

Je l'ai conçu, illustré et développé seul.

## 🇬🇧 In English

My personal website, bringing together my two jobs: frontend developer and illustrator.

- **Art**: illustrations, characters, traditional drawings, studies and animations (with drawing timelapses)
- **Dev**: my games (Ahoy!, La Haute Tour) and my tech talks

I designed, illustrated and built it on my own.

## Stack

Vue 3 · TypeScript · Vite · Tailwind CSS 4 · Vitest · Netlify

## Lancer en local / Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```
